Frequently Asked Questions

What is BAATCHEET? +

BAATCHEET is a secure, lightweight real-time messaging application optimized for speed, reliability, and minimal server footprints.

How secure is passwordless authentication? +

Passwordless authorization guarantees that access is linked directly to inbox ownership, preventing data leaks or credentials cracking.

Where is conversation data stored? +

Metadata and active dialogues are compiled in a protected Google Firebase Cloud instance with granular read/write rules.
